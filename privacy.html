수집하는 정보

run-nerds는 계정 생성과 훈련 코칭을 위해 이메일, 러너 이름, 목표 대회와 목표 기록, 훈련 가능 요일, 최근 컨디션, 통증 상태, 수면/피로 상태, 훈련 기록, 코치 대화 내용을 저장할 수 있습니다.

사용 목적

수집한 정보는 로그인, 사용자별 워크스페이스 동기화, 주간 훈련 계획 생성, 훈련 완료 기록, 회복/부상 위험을 고려한 코치 응답 제공, 앱 품질 개선을 위해 사용합니다.

저장 및 처리 위치

계정과 앱 데이터는 Supabase Auth 및 Supabase 데이터베이스에 저장됩니다. AI 코치 기능을 사용할 때는 프로필, 체크인, 주간 계획, 훈련 기록, 최근 코치 대화가 Supabase Edge Function을 통해 OpenAI API로 전달될 수 있습니다.

저장하지 않는 정보

OpenAI API key, Supabase service role key, 데이터베이스 접속 URL 같은 서버 비밀키는 브라우저 앱이나 모바일 앱 번들에 포함하지 않습니다. 결제 정보, 위치 추적, 연락처, 사진, 건강 플랫폼 원본 데이터는 현재 앱에서 직접 수집하지 않습니다.

보관 및 삭제

사용자 데이터는 계정과 워크스페이스를 제공하는 동안 보관됩니다. 계정 삭제나 데이터 삭제가 필요한 경우 앱 운영자에게 요청하면 Supabase에 저장된 프로필과 워크스페이스 데이터를 삭제할 수 있습니다.

주의 사항

run-nerds는 러닝 훈련을 돕는 코칭 앱이며 의료 진단을 제공하지 않습니다. 통증, 부상, 질환이 있거나 위험 신호가 있을 때는 훈련을 줄이고 전문가의 진료를 받아야 합니다.
