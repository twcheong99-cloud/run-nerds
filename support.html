로그인이 되지 않을 때

이메일과 비밀번호를 다시 확인해 주세요. 이메일 인증을 사용하는 Supabase 프로젝트라면 가입 후 받은 인증 메일을 먼저 확인해야 로그인할 수 있습니다.

훈련 계획이 동기화되지 않을 때

네트워크 연결을 확인한 뒤 앱을 다시 열어 주세요. 오프라인 상태에서는 설치된 화면이 열릴 수 있지만 로그인, 코치 응답, 워크스페이스 저장은 연결 후 다시 진행됩니다.

코치 응답이 느리거나 실패할 때

AI 코치 기능은 Supabase Edge Function과 OpenAI API 상태에 영향을 받을 수 있습니다. 응답이 실패하면 앱은 가능한 경우 로컬 코치 엔진으로 기본 훈련 조정을 제공합니다.

데이터 삭제 요청

로그인할 수 있다면 앱의 마이페이지에서 계정 삭제를 시작해 주세요. 계정 삭제는 Supabase Auth 계정, 프로필, 워크스페이스, 훈련 기록, 코치 대화 데이터 삭제를 요청합니다.

로그인할 수 없으면 지원 채널로 요청해 주세요. 공개 이슈에는 비밀번호, 인증 코드, 민감한 건강 정보, 자세한 개인정보를 적지 마세요.
